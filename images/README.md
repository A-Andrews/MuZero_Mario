# images/

Generated figures, tracked in git so a result can be pointed at from a commit.

The [internship handoff figures](handoff/) add human completion/successful-speed context, the active-scope failure balance, independent three-arm confirmation, action/value diagnostics and a MuZero explanation. All five have PNG/PDF/SVG exports. [Scientific report](../docs/handoff/REPORT.md), [figure guide and regeneration](../docs/handoff/HANDOFF.md), [portable evidence](../docs/handoff/evidence.json). Render with `.venv/bin/python scripts/plot_project_handoff.py`; no inference or cluster data access required. These new figures preserve the historical artifacts below.

The PDF is vector and a few tens of KB — safe to commit. Regenerating overwrites
in place, so `git diff --stat images/` shows when a figure moved.

The updated figures describe controller changes on the same frozen checkpoints,
not newly trained weights. Speed dots condition on successful completion; the
rate panel counts every model attempt. Human time bands include successful
respawn lives and differ from model trial start conditions. Neither those bands
nor faster successful attempts establish human-level reliability. Incomplete
confirmation results are rejected by the plotting script. The original PDF/JSON
are retained unchanged. The new JSON companions record per-trial results,
checkpoint identities, and input hashes. No model inference is needed to render.

Active scope is based on converted human gameplay: 2-2 and 7-2 are excluded; 5-3 remains eligible but has no best.pt in this benchmark. See [HUMAN_LEVEL_SCOPE.md](../docs/HUMAN_LEVEL_SCOPE.md). Historical original benchmark artifacts are retained.
